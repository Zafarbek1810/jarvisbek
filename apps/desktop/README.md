# Desktop holati

Hozir desktop uchun responsive Next.js veb dasturi mavjud. Alohida Tauri/Electron paketi yaratilmagan va sinovdan o‘tkazilmagan. Mahalliy mikrofon uchun localhost yoki HTTPS kerak.

Tauri keyingi bosqichda kichik hajmli variant bo‘lishi mumkin, lekin Rust, WebView imzolash, yangilash siyosati va platforma sinovlari talab etiladi. Electron ko‘proq resurs sarflaydi. Ishonchli veb va mobil oqimlardan oldin native qadoqlash qo‘shilmaydi. Bu katalog tayyor native ilova deb hisoblanmasin.
